================================================================
  중앙대학교병원 영상의학과 업무일지 - 서버 설정방법 (배포용)
================================================================


[ 개요 ]
서버 PC 1대에서 앱을 실행하면, 같은 내부망(병원 Wi-Fi/유선)에 연결된
다른 PC에서 브라우저만으로 접속하여 사용할 수 있습니다.
별도 설치 없이 Chrome, Edge 등 브라우저로 접속합니다.


================================================================
  1단계 : 서버 PC 최초 설정 (처음 한 번만)
================================================================

★ [초기설정(관리자실행).bat] 파일을 우클릭 →
   "관리자 권한으로 실행" 선택

   이 파일 하나로 아래 두 가지가 자동 처리됩니다:
   (1) 방화벽 포트 1000 허용  →  영구 적용 (재설정 불필요)
   (2) 서버 자동 시작 등록    →  작업 스케줄러에 등록
                                  로그인 시 서버가 자동 시작됨

   ※ 최초 1회만 실행하면 됩니다.

   [ 왜 시작프로그램 폴더가 아닌 작업 스케줄러를 사용하나요? ]
   Windows 시작프로그램 폴더는 관리자 권한 실행이 불가능합니다.
   작업 스케줄러는 관리자 권한(높은 권한)으로 실행할 수 있어
   방화벽 설정 등 권한이 필요한 작업에 적합합니다.


================================================================
  2단계 : 서버 시작 (수동으로 시작할 때)
================================================================

[ 방법 A ] 콘솔창 표시 (상태 확인 가능)
   - [서버시작.bat] 더블클릭
   - 검은 콘솔창이 열리고 서버가 실행됩니다.
   - 이 창을 닫으면 서버가 종료됩니다.

[ 방법 B ] 백그라운드 실행 + 브라우저 자동 열기
   - [시작.bat] 더블클릭
   - 콘솔창 없이 백그라운드로 서버가 시작됩니다.
   - 잠시 후 브라우저가 자동으로 열립니다.

접속 주소 (서버 PC에서):
   http://localhost:1000


================================================================
  자동 시작 해제 방법
================================================================

   [자동시작해제.bat] 더블클릭
   - 작업 스케줄러에서 자동 시작 항목이 제거됩니다.


================================================================
  3단계 : 다른 PC에서 접속 설정
================================================================

[ 서버 PC의 IP 주소 확인 방법 ]
   1. 서버 PC에서 명령 프롬프트(cmd) 실행
   2. ipconfig 입력 후 엔터
   3. 'IPv4 주소' 항목의 값 확인
      예) 192.168.1.100

[ 다른 PC에서 접속하는 방법 ]

   방법 1) 브라우저 주소창에 직접 입력
      http://서버IP:1000
      예) http://192.168.1.100:1000

   방법 2) 바탕화면 바로가기 생성
      - [클라이언트바로가기만들기.bat] 을 다른 PC에 복사 후 실행
      - 서버 IP 입력 시 바탕화면에 바로가기 자동 생성


================================================================
  파일 목록 및 용도
================================================================

  app.py                        메인 서버 프로그램 (직접 수정 불요)
  초기설정(관리자실행).bat      ★ 최초 1회 실행 (방화벽+자동시작 등록)
  서버시작.bat                   서버 수동 시작 (콘솔창 표시)
  시작.bat                       서버 백그라운드 시작 + 브라우저 열기
  자동시작해제.bat               자동 시작 해제
  방화벽설정(관리자실행).bat     방화벽만 단독 설정 시 사용
  클라이언트바로가기만들기.bat   다른 PC 바탕화면에 바로가기 생성
  instance/worklog.db            데이터베이스 파일 (백업 시 이 파일 복사)

================================================================
  문제 해결
================================================================

  Q. 다른 PC에서 접속이 안 됩니다.
     1. 서버 PC에서 서버가 실행 중인지 확인
     2. 초기설정.bat 을 관리자 권한으로 실행했는지 확인
     3. 서버 PC와 클라이언트 PC가 같은 네트워크인지 확인

  Q. 서버 시작 시 오류가 납니다.
     1. Python이 설치되어 있는지 확인 (cmd → py --version)
     2. 서버시작.bat 을 다시 실행 (패키지 자동 설치됨)

  Q. 재부팅 후 서버가 자동 시작되지 않습니다.
     1. 초기설정(관리자실행).bat 을 관리자 권한으로 다시 실행
     2. 작업 스케줄러(taskschd.msc)에서
        '영상의학과업무일지_서버' 항목 확인

  Q. 포트를 변경하고 싶습니다.
     - app.py 마지막 줄의 port=1000 을 원하는 번호로 변경
     - 방화벽설정.bat 의 localport=1000 도 동일하게 변경
     - 모든 bat 파일의 :1000 도 동일하게 변경
