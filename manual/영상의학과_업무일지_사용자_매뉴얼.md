# 영상의학과 업무일지 사용자 매뉴얼

본 매뉴얼은 중앙대학교병원 영상의학과의 업무 내역을 효율적으로 관리하기 위한 **업무일지 시스템**의 사용 방법을 안내합니다.

---

## 1. 시스템 접속 및 로그인

### 1.1 시스템 접속
웹 브라우저(Chrome, Edge 권장) 주소창에 아래 주소를 입력하여 접속합니다.
*   **내부망 접속 주소**: `http://[서버IP]:1000`

### 1.2 로그인
1.  부여받은 **아이디**와 **비밀번호**를 입력합니다.
2.  로그인 후 우측 상단에서 본인의 이름과 권한(관리자/사용자)을 확인합니다.
    > **주의**: 초기 비밀번호를 사용하는 경우, 보안을 위해 관리자에게 요청하여 비밀번호를 변경하시기 바랍니다.

---

## 2. 메인 대시보드 활용

로그인 후 첫 화면인 대시보드에서는 오늘의 주요 현황을 한눈에 파악할 수 있습니다.

*   **상단 KPI 배지**: 미해결 이슈, 오늘 휴가자, 오늘 On-call 등 주요 지표 숫자가 표시됩니다.
*   **상세 정보 확인 (툴팁)**: 각 배지 위에 마우스를 올리면 상세 명단이나 내용이 팝업으로 나타납니다.
*   **오늘의 업무 현황**: 화면 하단에는 근무자 현황부터 특이사항까지 오늘 기록된 모든 데이터가 섹션별로 요약 표시됩니다.
*   **바로가기**: 각 섹션 우측의 버튼을 클릭하면 해당 날짜의 업무일지 작성 페이지로 즉시 이동합니다.

---

## 3. 업무일지 작성 방법

왼쪽 메뉴의 **[업무일지 작성]**을 클릭하여 기록을 시작합니다.

### 3.1 날짜 선택
*   기본적으로 오늘 날짜가 선택되어 있습니다. 과거 날짜의 일지를 작성하거나 수정하려면 상단 날짜 선택기에서 날짜를 변경합니다.

### 3.2 주요 작성 항목 (7개 섹션)
1.  **근무자 현황**: 오전/종일/야간별 근무 인원과 직종을 등록합니다.
2.  **휴가 현황**: 연차, 반차, 병가 등 휴가 종류와 대상자를 입력합니다.
3.  **On-call**: 모달리티별(CT, MRI 등) 담당자와 연락 가능한 시간대, 내용을 기록합니다.
4.  **연장근무**: 성명과 시작/종료 시간을 입력하면 총 연장 시간이 자동 계산됩니다.
5.  **장비 이력**: 장비 고장, 정기 점검, 수리 완료 내역을 엔지니어 정보와 함께 기록합니다.
6.  **인수인계**: 다음 근무자에게 전달할 중요 사항을 우선순위(일반/중요/긴급)에 따라 작성합니다.
7.  **특이사항·이슈**: 환자 관련 이슈, 행정 사항 등 특이사항을 기록하고 처리 상태를 관리합니다.

---

## 4. 저장 및 제출 프로세스

작성이 완료되면 페이지 하단의 **[저장]** 버튼을 클릭합니다.

1.  **데이터 저장**: 입력한 정보가 데이터베이스에 저장됩니다. (아직 목록에는 나타나지 않음)
2.  **제출 확인**: 저장 후 나타나는 팝업에서 **[예]**를 누르면 공식적으로 제출됩니다.
    *   **제출 완료**: 업무일지 리스트에 등록되며, 일반 사용자는 직접 수정이 불가능해집니다.
    *   **제출 안 함**: 단순 저장 상태로 유지되며, 나중에 다시 수정하여 제출할 수 있습니다.

---

## 5. 업무일지 리스트 및 반려 시스템

### 5.1 일지 확인
*   **[업무일지 리스트]** 메뉴에서 날짜별 제출 현황을 확인합니다.
*   각 날짜 옆의 **도트 배지**는 해당 날짜에 기록된 항목 수를 나타냅니다.

### 5.2 반려 및 수정
*   관리자가 일지 보완을 요청하며 **[반려]** 처리한 경우, 작성 페이지 상단에 '반려됨' 표시가 나타납니다.
*   반려된 일지는 작성자가 내용을 수정한 후 다시 **[저장 및 제출]** 할 수 있습니다.

---

## 6. 인쇄 및 보고

공식 보고를 위해 업무일지를 인쇄할 수 있습니다.

1.  업무일지 리스트나 작성 페이지 상단의 **[인쇄]** 버튼을 클릭합니다.
2.  **인쇄 미리보기**: A4 규격에 최적화된 화면이 나타납니다.
3.  **결재란 확인**: 우측 상단의 결재란(파트장, 팀장, 진료과장)이 포함되어 있는지 확인합니다.
4.  **출력**: 브라우저 인쇄 기능(Ctrl + P)을 사용하여 종이로 출력하거나 PDF로 저장합니다.
